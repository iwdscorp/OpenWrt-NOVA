Implemented
-----------
Separate purpose-specific Zones/forwarding, Traffic policy, DNAT, SNAT and IPset
workspaces. Compact horizontally scrollable policy tables with sticky headers,
source/destination/service/schedule/action columns, green allow/red deny/blue NAT
badges, search, configured-state filter and sequence/source-destination grouping.
Three explained zone-default policies, native member networks/masquerade state,
actual configured one-way inter-zone forwarding paths. No duplicated native lists
in the default workspace; the complete native map is preserved in a disclosure.
Edit/Add delegates to the actual LuCI buttons. Delete/Clone/Reorder/general flags/
offloading remain in that native editor. Save & Apply and reset stay LuCI-owned.
SNAT UCI src displayed correctly as outbound zone, with MASQUERADE automatic
address and ACCEPT no-rewrite semantics, not a misleading traffic-allow badge.
Match details are plain text with explicit ICMP/MAC/device/mark/limit/log/IPset
and other advanced options; NAT schedules available in details. Configured text
is appended through text nodes, bypassing native E's scalar-as-HTML behavior.
Pending inline checkbox/dropdown state is read. Native rerender reattaches the
presentation; migration/loading/missing-grid fallback leaves the native page.
Persian + English own copy, existing fonts and logical direction/alignment.
No UCI/RPC writes by the module; no cloned native controls or reordered native cells.

Boundaries
----------
This is an OpenWrt presentation, inspired by FortiGate sequence/interface-pair
views, not a FortiGate firewall engine or UTM suite. No invented hit counters,
policy lookup, IPS/app-control, traffic-per-rule graphs or security verdicts.
Policy list is UCI configuration, not all live nftables/generated PassWall rules.
No fresh browser rendered/visual/mobile QA or live native modal/save/apply/reorder
checks were executed. Previously blocked localhost browser access was not bypassed
with another browser, raw CDP, HTTP page fetch or indirect screenshots. Code-only
DOM tests are not rendered-page or full native interactive workflow evidence.
Other firmware versions and firewall3 migration are not runtime-verified.
Existing APK repository-cache warnings and WSL read-only disk-fallback warning
were retained; package verify/install succeeded without changing repos or global
signature verification. Only the unsigned local package uses allow-untrusted.
