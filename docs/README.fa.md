# NOVA · رابطی روشن‌تر برای OpenWrt

قالب بومی LuCI با فونت فارسی، راست‌چین فارسی و چپ‌چین انگلیسی، نمودارهای واقعی ترافیک و نمای سیاست‌محور فایروال. NOVA داشبورد نمایشی یا جایگزین API روتر نیست؛ تنظیمات و کنترل‌های اصلی همچنان متعلق به LuCI هستند.

[English](../README.md) · [راهنمای نصب](INSTALL.md) · [انتشار ۲.۸.۱](releases/v2.8.1.md) · [وضعیت تست‌ها](VERIFICATION.md)

## امکانات

- فونت Estedad محلی، ترجمهٔ بومی و چیدمان مستقل فارسی/انگلیسی.
- فایروال با نماهای جدا برای قوانین ترافیک، DNAT، SNAT، زون‌ها و مجموعه‌های آدرس.
- جستجو، فیلتر وضعیت، ترتیب پیکربندی و گروه‌بندی مبدأ/مقصد.
- نمودار زندهٔ دریافت/ارسال، مقایسهٔ اینترفیس‌ها، روند حافظه و میانگین بار سیستم.
- ارتقای جدول‌ها، کنترل‌ها و ناوبری LuCI و هماهنگی با PassWall 2 نصب‌شده.
- CSS کامپایل‌شده و فونت محلی؛ بدون Node.js یا CDN روی روتر.

## سازگاری

بستهٔ فعلی `luci-theme-nova-2.8.1-r1.apk` است. آزمایش واقعی روی OpenWrt 25.12.5 x86_64، LuCI openwrt-25.12 با قالب ucode و PassWall 2 26.9.16-r1 انجام شده است.

**APK این پروژه بستهٔ OpenWrt است، نه برنامهٔ اندروید.** برای `opkg` و نصب IPK مناسب نیست. `noarch` بودن بسته نیز به معنی تأیید سازگاری با همهٔ نسخه‌های LuCI نیست. نسخه‌های دیگر و PassWall 1 تأیید نشده‌اند.

## نصب بدون SFTP

ابتدا از تنظیمات روتر پشتیبان بگیرید.

۱. پس از انتشار در GitHub، فایل APK و checksum را از همان Release دریافت و SHA-256 را بررسی کنید.

۲. در LuCI به «سامانه ← بسته‌های نرم‌افزاری ← بارگذاری بسته» بروید و APK را بارگذاری کنید.

۳. فقط همین بستهٔ محلی امضانشده را مجاز کنید؛ بررسی امضای کل بسته‌ها را غیرفعال نکنید.

۴. در «سامانه ← سامانه ← زبان و ظاهر»، قالب NOVA و زبان فارسی یا English را انتخاب کنید؛ «ذخیره و اعمال» و سپس Ctrl+F5.

اگر فایل از قبل در `/tmp` قرار دارد:

</div>

```sh
apk add --no-network --allow-untrusted /tmp/luci-theme-nova-2.8.1-r1.apk
/etc/init.d/uhttpd restart
```

## فایروال چه تفاوتی دارد؟

«قوانین ترافیک» اجازه/رد را با مبدأ، مقصد، سرویس و زمان‌بندی نشان می‌دهد. «DNAT» انتشار سرویس بیرونی روی میزبان داخلی است. «SNAT» آدرس مبدأ خروجی را بازنویسی می‌کند؛ زون آن، زون خروجی است. «زون‌ها» سیاست ارتباط با روتر، عبور داخل زون، شبکه‌های عضو و مسیرهای یک‌طرفهٔ بین زون‌ها را توضیح می‌دهد. «مجموعه‌های آدرس» اشیای تطبیق هستند و به‌تنهایی اجازهٔ دسترسی ایجاد نمی‌کنند.

دکمه‌های ویرایش و ایجاد به فرم اصلی LuCI وصل‌اند. حذف، تکثیر، ترتیب قوانین و تنظیمات عمومی زیر «ویرایش پیشرفته / ترتیب قوانین» حفظ شده‌اند. جستجو و گروه‌بندی، ترتیب واقعی قوانین را تغییر نمی‌دهند.

در SNAT گزینهٔ `ACCEPT` یعنی **عدم بازنویسی آدرس**، نه اجازهٔ ترافیک. این نما پیکربندی UCI است؛ شمارندهٔ اجرای قوانین یا فهرست همهٔ قواعد زندهٔ تولیدشده توسط PassWall/اسکریپت‌ها نیست. طراحی از نمای سیاست‌های FortiGate الهام گرفته، اما موتور فایروال همچنان OpenWrt است و قابلیت UTM/IPS ساخته نشده است.

## نمودارها واقعی‌اند، اما تاریخچهٔ دائمی نیستند

سرعت از اختلاف شمارندهٔ بایت و زمان دو نمونه به‌دست می‌آید. تاریخچه از زمان بازشدن صفحه شروع می‌شود و بازه‌های ۱/۳/۱۵ دقیقه دارد. برای اولین سرعت باید دو نمونه دریافت شود. قطع داده یا بازنشانی شمارنده، شکاف ایجاد می‌کند و با عدد ساختگی پر نمی‌شود.

دریافت/ارسال هر دستگاه جداست؛ جمع گمراه‌کنندهٔ LAN/WAN/پل به عنوان مصرف اینترنت نمایش داده نمی‌شود. میانگین بار یک دقیقه، درصد مصرف CPU نیست. شمارندهٔ بسته‌ها/افت‌ها، مصرف هر کاربر یا هر قانون نیست. کاهش حرکت سیستم و خاموش‌کردن انیمیشن رعایت می‌شود.

## چه چیزهایی تأیید شده؟

ساخت و تست کد، نصب واقعی APK، کامپایل سه قالب ucode، تطابق فایل نصب‌شده با سورس و ترجمه‌های بومی تأیید شده‌اند. هنگام نصب، تنظیمات شبکه، فایروال و PassWall تغییر نکردند. پنج نمای فایروال در هر دو زبان با تست DOM کدمحور بررسی شده‌اند.

**بررسی تصویری تازهٔ مرورگر/موبایل، گردش زندهٔ ویرایش/ذخیره/اعمال/ترتیب، وایرلس واقعی و اتصال VPN یا اشتراک زنده هنوز تأیید نشده‌اند.** تست کد جایگزین تست واقعی رابط نیست؛ تصویر نمایشی نیز به‌عنوان اسکرین‌شات واقعی ارائه نشده است.

## توسعه و مجوزها

توسعه با Node.js 24 و npm؛ روی ویندوز در صورت محدودیت PowerShell از `npm.cmd` استفاده کنید. اجرای `npm ci`، سپس `npm run build` و `npm test` برای تست‌های محلی کافی است. پیش‌نیازهای بسته‌سازی در [راهنمای انتشار](RELEASING.md) آمده‌اند.

کد اختصاصی NOVA مجوز MIT دارد؛ اجزای مشتق از LuCI دارای Apache-2.0، ترجمهٔ PassWall و کاتالوگ ادغام‌شده دارای GPL-3.0 و فونت‌ها دارای OFL هستند. مجموعهٔ منتشرشده «فقط MIT» نیست. [منشأ ترجمه‌ها و مجوزها](../TRANSLATION-NOTICE.txt) حفظ شده‌اند.
