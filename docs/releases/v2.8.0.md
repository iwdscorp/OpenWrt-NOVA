# NOVA 2.8.0-r1 · Firewall Policy & Objects

**Prepared release notes — not yet published on GitHub.**

A native, bilingual firewall workspace over the existing LuCI forms. The release adds no demo firewall rule and does not replace OpenWrt's firewall engine.

## Highlights

- Purpose-specific traffic policy, DNAT, SNAT, zone/forwarding and address-set lists.
- Explicit source/destination/service/schedule/action columns instead of interchangeable match blobs.
- Search, configured-state filters and sequence/source-destination grouping.
- Explained router input/output/forward defaults and actual one-way forwarding paths.
- Original LuCI editor retained for native settings, delete, clone and rule ordering.
- Correct SNAT exit-zone and no-rewrite semantics; text-safe configured labels.
- Persian RTL and English LTR copy and layout; real telemetry from 2.7 retained.

## Install / upgrade

Use LuCI **System → Software → Upload Package**, or after placing the file in `/tmp`:

```sh
apk add --no-network --allow-untrusted /tmp/luci-theme-nova-2.8.0-r1.apk
/etc/init.d/uhttpd restart
```

Select NOVA and your language under **Language and Style**, then reload without cache. See [installation and recovery](../INSTALL.md).

## Verification and limits

Local upgrade 2.7 → 2.8, builds/tests, native template compiles, catalog checks and installed hashes passed on OpenWrt 25.12.5 x86_64 / LuCI openwrt-25.12. Firewall/network/PassWall2 configuration hashes were unchanged.

Fresh browser/mobile visual QA and live modal/save/apply/reorder checks remain unverified. Other firmware, PassWall 1, live wireless/VPN and subscriptions were not validated. The policy list is UCI configuration, not every generated live nftables rule. No policy hit counts, UTM/IPS or persistent/per-client accounting are provided.
